# Python - 1 - Array

## Requirements

- python3.10
- flake8
- `make`

## How to use

In each directory you will find a Makefile that provides all necessary commands such as :

### `make`

If missing, creates the virtual environment and runs the program. If the exercise was to create a function, runs the tests
instead.

### `make venv`

Creates the virtual environment with all necessary dependencies.

### `make test`

If missing, creates the virtual environment and runs the tests.

### `make fclean`

Deletes the `__pycache__` and `venv` directories.
